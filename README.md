# Mohamed Ahmed Samir — Portfolio

Personal portfolio website built with HTML, CSS, and JavaScript, hosted on GitHub Pages.

## Live site
https://Smymy20.github.io

## Structure
- `index.html` — page content and structure
- `style.css` — styling and responsive layout
- `script.js` — populates skills/projects/education and handles the contact form + mobile nav
- `images/` — profile photo and project screenshots

## Sections
Home · About · Skills · Projects · Education & Experience · Contact

## Before deploying
- Replace `images/profile.jpg` with a real photo
- Replace `YOUR-USERNAME` links (GitHub, project repos) and email in `index.html` / `script.js`
- Optionally connect the contact form to Formspree or EmailJS so it actually sends messages
